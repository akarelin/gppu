# Build gppu 3.6.0

Publish the Python 3.14 artifacts for the existing `gppu/v3.6.0` tag through the `gppu` GitHub Actions workflow.

## Required result

- [ ] Linux jobs select Five; the release build uses its existing `python3` command.
- [ ] The existing release contains the built artifacts.
- [ ] The workflow completes successfully for `gppu/v3.6.0`.
- [ ] The versioned release and `gppu/latest` contain the 3.6.0 wheel and source distribution.
