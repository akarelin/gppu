# The REST surface

`mixin_Rest` gives an application an object surface generated from its classes: every object it registers answers for its own members. `AsyncApp` carries it; any app composes it (`class API(mixin_Rest, App)`). Alex, 2026-09-12: "all of y2 should expose its entities' public methods natively through base classes as rest api. Documentation and manifest should be autogenerated from code. Do it with no additional code in y2 classes." and "REST is a tiny change to AsyncApp".

The walk covers the classes born under `Env.app_path`. A member is the application's when every class in the MRO that defines its name is born there, so nothing a gppu base defines — the lifecycle, `_DC`'s dict protocol, the loggers — is ever exposed. A member is a *value* (a `_DC` field, a property, or a parameterless method named in `rest_read_methods`) or a *command* (a method carrying `rest_command = True`, one granted by class name in `rest_commands` with every parameter defaulted, or a name the object lists in its own `commands`, which dispatches through its `command()`). Names in `rest_redact` are never members. The host sets those three from its configuration and names its rosters in `rest_registries()`, as an app sets `connection` for `mixin_Mqtt`.

```python
class API(mixin_Rest, App):
  def initialize(self):
    self.rest_read_methods = tuple(Env.glob_list('rest/read_methods'))
    self.rest_redact       = tuple(Env.glob_list('rest/redact'))
    self.rest_commands     = Env.glob_dict('rest/commands')
  def rest_registries(self):
    return {'entity': State.entities, 'app': Runtime.apps}
```

Four calls, each answering `(payload, status)`; the transport is the host's:

| call | answers |
|---|---|
| `rest_manifest` | the classes and their members, walked once |
| `rest_objects(kind=None, full=False)` | `registry/key -> class`, or the full payload of each |
| `rest_read(registry, key, name=None)` | an object's payload, or one value; a command answers 405 |
| `rest_call(registry, key, name, body)` | binds the body to the signature (exact names, scalar casts), dispatches, answers the result |

A value that is an object of the application is answered as its address (`registry/key`), never its repr. A command runs in the loop's executor unless it is a coroutine function, which is awaited.
